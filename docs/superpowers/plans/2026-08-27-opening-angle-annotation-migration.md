# 轴端开角标注迁移实施计划

1. 在 `engineering-annotation` 添加开角事实类型和镜像斜线测量测试，覆盖左右开角、90°、中部干扰线与折线段。
2. 添加轴端选择和嵌套布局测试，固定旧 Web 端的筛选阈值、稳定键与五点布局契约。
3. 实现测量、选择和布局模块，并导出公共入口。
4. 扩展 `planEngineeringAnnotations`，把开角投影为 angular intent、annotation、association 和批量创建程序。
5. 添加 Viewer 组件测试，先证明当前五点被错误渲染为折线，再实现圆弧、延长线和切向箭头。
6. 扩展 DSH host 工具测试，验证自动标注经第一层扩展 seam 提交开角目标。
7. 添加真实 DXF 集成脚本或测试，核验导入、识别、规划结果及确定性。
8. 运行相关包测试、类型检查、构建和真实样本自测；审查差异后提交 PR 并合并 main。
