# 自适应图元分段与拓扑部件选择设计

## 1. 目标

本次迁移解决两个互相影响的根因：

1. 清洁线稿中的一条骨架链只能提升为一个解析图元，导致本应独立的相邻直线被保留成共享 Polyline。
2. 语义编辑使用区域求交授权图元，导致与目标空间重叠、但拓扑上不属于目标的路径被一起修改。

迁移后的系统必须满足：

- 明显由多个解析图元组成的骨架链可以一对多提升。
- 分段阈值不得依赖固定像素值，缩放图纸后决策保持一致。
- 平滑轮廓、轻微锯齿和有机曲线不得被无意义地拆碎。
- 底层图元可以适度分段，但通过 CompoundPath 保持同一逻辑整体。
- 模型通过语义种子和接口节点表达目标，后端沿显式拓扑提取目标子图。
- 搜索区域只负责裁剪视觉上下文，不再授予几何写权限。

## 3. 自适应分段算法

### 3.1 尺度变量

算法使用以下尺度：

- `D`：整张图纸包围盒对角线。
- `W`：整张图纸的稳健中位线宽。
- `L`：当前骨架链的弧长。

所有长度门槛都由 `D`、`W`、`L` 的比例产生，不设置固定像素阈值。角度、误差比和收益值是无量纲常数，可以固定并通过回归集校准。

初始验证采用：

```text
fitTolerance = max(0.50 × W, 0.00030 × D)
nearWindow   = max(2.00 × W, 0.00250 × D)
farWindow    = max(4.00 × W, 0.00500 × D)
minimumSpan  = max(4.00 × W, 0.00500 × D, 0.03 × L)
```

这些比例是回归配置，不散落在拟合代码中。生产实现必须输出实际使用的尺度和得分，便于审计和重新标定。

### 3.2 候选拐角生成

对每个骨架链按弧长采样，在 `nearWindow` 和 `farWindow` 两个尺度分别使用 PCA 估计进入与离开方向。

候选拐角同时满足：

1. 近尺度和远尺度的方向变化均超过角度门槛。
2. 两个尺度的角度比达到稳定门槛，排除平滑圆弧中随窗口扩大而增长的曲率。
3. 候选点到链两端及相邻候选点的距离不小于 `minimumSpan`。
4. 同一个线宽范围内的连续候选合并成一个“拐角区”，只保留得分最高的候选。

### 3.3 候选验证与模型选择

候选点不会因为角度足够大而直接成为分段点。系统在候选附近搜索最优切点，并分别拟合左右局部窗口。

```text
splitGain = (
  combinedRobustError
  - weightedChildRobustError
) / fitTolerance

acceptScore = splitGain - splitPenalty
```

初始 `splitPenalty` 为 1.5 个归一化容差单位；实验已覆盖 1.0～2.0，问题链在整个区间内决策不变。每新增一个内部边界都单独支付一次 `splitPenalty`，因此增加更多图元必须持续带来新的拟合收益。

只有在以下条件同时满足时才拆分：

- 左右子段均能稳定拟合为 Line、Arc 或其他已支持的解析图元。
- `acceptScore > 0`。
- 新子段均达到 `minimumSpan`。

`splitPenalty` 与 `minimumSpan` 共同构成复杂度惩罚，避免为了降低少量误差生成大量短图元。

### 3.4 解析图元优先级

处理顺序为：

1. 整链可稳定拟合成 Circle、Ellipse、Arc 或 Line 时，保留整链解析图元，不进入分段。
2. 整链无法稳定拟合时，运行多尺度拐角检测和局部模型选择。
3. 可解释的子段提升为 Line、Arc、Circle、Ellipse。
4. 无法稳定解释的剩余部分保留为 Polyline；后续支持 Spline 时可以提升为 Spline。

闭合链必须使用循环索引处理首尾连接，不能把数组首尾当成天然断点。

### 3.5 拟合与接点解析分离

每个子段先独立拟合最佳解析支撑曲线，拟合器不为了命中骨架切分点而扭转直线，也不因为有限图元端点存在缝隙就退回 Polyline。相邻成员随后进入单独的 CAD 接点解析阶段：

- Line–Line：求两条无限支撑直线的交点，并把两条有限直线裁剪或延长到该交点。
- Line–Arc：求无限直线与支撑圆的交点，选择最接近原始切分点的解。
- Arc–Arc：求两支撑圆交点，选择最接近原始切分点的解。
- Polyline/Spline 与解析图元相邻时，使用边界段或端部切线作为局部支撑线；只有确实无法解析接点时才保留未解析状态，不能谎报 `connected`。

原始骨架切分点只用于在多解中消歧，不强迫解析图元穿过该采样点。`connected` 关系只能在相邻成员的真实几何端口完成同点闭合后创建；它是内部拓扑事实，不属于用户标注，普通画布不得显示其文字标签。

### 3.6 骨架闭合循环重建

骨架图中的分叉节点会把一条真实闭合轮廓拆成多条开放链。进入单链分段前，系统先枚举共享同一对端点邻域的互补开放路径，并把候选路径联合成闭合样本：

1. 两条路径必须共享两个端口，而不是只在一端相接。
2. 端口匹配容差由全图中位线宽与图纸对角线共同产生。
3. 联合样本必须通过一次整体 Circle 拟合，P95 误差不得超过自适应拟合容差。
4. 不能根据两段 Arc 的半径相似度直接合并。
5. 当 Circle 与轻微 Ellipse 都通过时，若长短轴差异小于拟合容差，认为栅格数据无法区分二者，优先自由度更低的 Circle。
6. 合并记录来源链数量、端口容差、拟合容差、P95 误差和接受原因，以供审计与回归。

重建出的 Circle 仍可在原分叉位置与外部 Line/Arc 建立拓扑接口，但这些接口不得再次把 Circle 的几何表达拆回多段 Arc。

## 4. CompoundPath 逻辑整体

一条来源骨架链可以产生多个 Drawing IR 图元，但同时生成一个不可渲染的逻辑容器：

```ts
interface CompoundPath {
  id: string;
  memberIds: GeometryId[];
  sourceChainId: string;
  closed: boolean;
  ordered: boolean;
  junctions: PathJunction[];
}

interface PathJunction {
  atMemberIndex: number;
  point: Vec2;
  kind: 'continuous' | 'corner' | 'topology';
}
```

约束：

- `memberIds` 按原始路径顺序排列。
- CompoundPath 本身不复制几何数据，也不改变渲染结果。
- 默认选择、移动、删除和模型摘要把 CompoundPath 当作一个逻辑对象。
- 精确编辑和拓扑寻路可以访问内部成员与接口节点。
- 每个成员保留相同的 `sourceChainId` 和原始采样范围，支持审计、回归和重新拟合。

CompoundPath 是路径身份，不是 CAD 图块或图层，不引入实例化和样式继承语义。

## 5. 全局几何拓扑图

Drawing IR 每个 revision 派生一个 `GeometryTopologyGraph`。图包含：

- 解析图元端点。
- Polyline/Spline 的稳定顶点与参数化虚拟端口。
- 经导入或审计确认的真实连接点。
- CompoundPath 内部的有序连接关系。
- Drawing IR 已存在的显式拓扑关系。

视觉相交不得自动成为拓扑连接。只有显式关系、共享稳定端点或经过容差验证并记录证据的连接，才允许建立图边。

拓扑图绑定 revision。几何事务提交后旧图失效并增量重建受影响区域。

## 6. 语义节点与部件子图提取

模型不再返回“区域内所有可修改图元”，而是输出以下稀疏视觉接地契约：

```ts
interface SemanticAnchorProposal {
  id: string;
  point: NormalizedPoint;
  role: 'target-seed' | 'boundary' | 'required' | 'protected-seed';
  confidence: number;
}
```

模型负责语义判断：目标内部在哪里、目标与外部结构的接口在哪里、哪些相邻分支必须保护。后端负责确定性几何：

1. 通过 Observation 坐标变换把归一化锚点转换为世界坐标。
2. boundary 吸附到 revision 对应的真实拓扑顶点，其余锚点吸附到真实原子边。
3. 从 target seed 出发沿真实邻接遍历，在 boundary 停止，并阻止进入 protected seed 分支。
4. required 锚点作为必须覆盖的路径证据；同一源图元可形成目标区间和保护区间。
5. 解析通过后直接生成确定性写授权；不再增加第二次“候选片段选择”模型调用。
6. 锚点缺失、保护冲突或遍历超预算时，把结构化缺陷反馈给下一次接地；没有足够证据时拒绝，不扩大搜索区域并授权全部交集。

搜索区域只用于裁剪截图、降低上下文和限制候选枚举范围，不参与最终写权限计算。

## 7. 通用预期结果

迁移后，一条由明显转角连接的共享来源链产生：

- 一条斜向 Line。
- 一条竖直 Line。
- 一个由两条最佳拟合直线延长或裁剪所得的精确交点。
- 一个包含上述来源关系的 CompoundPath。

当用户只要求修改斜向分支时：

1. 模型给出斜向分支内部的 target seed、连接处 boundary 和竖直分支 protected seed。
2. 后端沿全局拓扑提取 boundary 以内的目标路径。
3. 竖直分支在接口处被截断，不进入授权子图。
4. 修改后验证接口仍连接、保护区间哈希不变且没有新悬空端点。

## 8. 回归与可审计性

正式实现必须包含：

- 问题链拆成两条 Line 的确定性测试。
- 同一链多倍率缩放后分段索引一致的测试。
- 平滑有机曲线不拆分的测试。
- 明显复合折线内部可分段、逻辑上只有一个 CompoundPath 的测试。
- 轻微锯齿线不拆分的测试。
- 闭合曲线首尾连续的测试。
- 视觉相交但无拓扑关系的图元不会进入部件子图的测试。
- 同一共享 Polyline 中 target seed 与 boundary 只提取目标区间、不提取 protected 区间的集成测试。

每次分段记录：算法版本、`D/W/L`、候选点、角度、多尺度稳定比、父子拟合误差、复杂度惩罚、接受或拒绝原因。每次部件选择记录：revision、模型锚点、吸附结果、候选子图、评分和最终授权集合。
