# 2D CAD Core v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Spatial Protocol to v0.2 with explicit 2D CAD geometry, text, and associative dimensions across validation, patches, rendering, editing, audit replay, and DXF export.

**Architecture:** The protocol uses a discriminated union of native CAD entities. Compiler and Validator own normalization and invariants; Patch remains atomic and reversible. SVG and DXF are adapters over the same canonical entities.

**Tech Stack:** TypeScript 5.8, React 18/SVG, Vitest 3, DXF text export.

## Global Constraints

- 2D only; do not add layers, blocks, hatches, 3D, DWG, STEP, or a constraint solver.
- Preserve Point/Line/Circle field compatibility and deterministic 0.1 audit replay.
- Angles are degrees, zero on +X, counterclockwise positive.
- Never approximate a supported native curve into lines inside Spatial Core.
- Low-confidence valid entities may commit but retain entity confidence and render red.
- Work on `main` with the main agent only.
