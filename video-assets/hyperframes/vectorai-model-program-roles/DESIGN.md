# VectorAI Model / Program Roles — Visual Identity

## Style Prompt

延续维构 AI 的精密二维工程可视化：透明画布上悬浮深色半透明面板，以蓝灰色显示模型判断、图元映射、坐标、端点和连接关系。动画像 CAD 捕捉、事务编译和矢量编辑过程，清晰表现“模型做智能判断，程序做确定性数学”。

## Colors

- `#D8DEE7` — 主要文字、正式矢量结果
- `#8DBDDD` — 模型判断、活动节点和主要路径
- `#6DA9D2` — 程序计算、连接线和面板边框
- `#E5B567` — 位移向量、固定锚点与诊断提示
- `rgba(9, 11, 14, 0.90)` — 半透明工程面板；根画布保持透明

## Typography

- `PingFang SC` — 中文标题与说明
- `JetBrains Mono` — 坐标、图元 ID、状态和读数

## Motion

- 模型侧使用柔和聚焦、候选锁定和目标脉冲。
- 程序侧使用线性传递、节点吸附、路径绘制和坐标求解。
- 空间求解场景逐帧重放外部浏览器最后一次成功审计 `run_660e24af-8d7f-4baa-9e14-9427956e63f6`：完整 58 个图元、手部圆心位移 `[30, 150]`、两条连接线在身体端锚点不动的前提下重算手端接点，并生成 3 条真实 `geometry.update`。
- 审计内部的 `minimum-deformation` 只用于有序搬运接触端口；视觉上必须表现为“手部平移 + 连接线端点重连”，不得表现为整条手臂刚性旋转。
- 原始图纸、抬手结果、图元 ID、前后坐标和 revision 全部来自持久化 drawing 与 commit 数据，不手工补画角色轮廓。
- 角色之间通过可见的任务包完成交接。
- 不使用无限循环；最终停留在可编辑矢量结果。

## What NOT to Do

- 不铺设不透明全屏背景。
- 不把模型表现成会自己计算精确坐标。
- 不使用随机粒子、紫色赛博渐变或游戏 HUD。
- 不用长段落代替图形化分工。
- 不把最终结果表现成扁平图片。
- 不使用 `test2-fixture` 或手绘近似图代替真实审计图纸。
- 不再使用旧的 `run_410c…` 旋转审计或任何手工估算的位移数据。
