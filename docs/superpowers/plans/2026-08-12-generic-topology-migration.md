# 通用视觉语义到二维拓扑迁移记录

> 日期：2026-08-12
>
> 状态：已实现并通过本地门禁

## 目标

把视觉搜索与几何写授权彻底分离，使模型通过少量通用锚点表达语义，后端通过当前 Drawing revision 的全局拓扑确定可编辑子图。任何对象类别、动作、画面方向或测试样例都不能进入生产决策规则。
